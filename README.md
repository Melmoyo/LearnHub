# LearnHub

A frontend learning management system for browsing courses, tracking progress, and managing educational content in a clean, structured interface.

## Features

- 📚 Browse available courses by category
- 🔍 Course detail view with curriculum breakdown
- 📊 Progress tracking per course
- 🎓 Dashboard showing enrolled courses and completion status
- 📱 Responsive layout for all screen sizes

## Tech Stack

- **JavaScript** — core application logic
- **HTML & CSS** — structure and styling
- **JSON** — mock course data

## Why I Built This

LMS platforms like Udemy and Coursera are complex products. Building a simplified version helped me understand how to architect a multi-view application with real navigation, state management across pages, and a content-heavy UI — all without a framework.
